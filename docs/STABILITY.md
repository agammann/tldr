# tldr v1

The supported delivery is a Node.js 24 local stdio MCP service with the matching 1.0.0 unpacked Chrome or Edge extension. The service returns source clauses, topic navigation and exact text differences. Your connected assistant writes the explanation; citations help inspect it but do not guarantee its meaning.

The prepared 1.0.0 source passed 23 tests, the website build and a dependency audit with no findings using Node 24.19.0 and pnpm 11.19.0 on Windows. Actual extension loading and capture passed in Chrome 155 and Edge 154 with matching service and extension versions. SDK checks exercised all five tools, 80 clauses across four source pages, exact revision differences, missing and malformed input, process restart and backup restoration.

The built website passed seven controlled interaction checks, including cancellation, citations, quotation rejection, clearing and reload, at desktop and narrow mobile widths. A separate first GPT-5.4 response to eight fictional source clauses passed all 16 frozen meaning and quotation criteria on independent review. That bounded result does not establish accuracy on every agreement.

The first complete review establishes a baseline for the exact captured URL. Selected or oversized captures remain explicitly partial and cannot overwrite a complete baseline. Read every source page before describing a long review as complete. Removed clauses use `OLD_C` references; current clauses use `C` references. Those IDs identify chunks of the supplied text, not legal section numbers. Linked policies are separate documents and must be reviewed separately.

The optional website review uses the visitor's own OpenAI key and API billing with GPT-5.4. It sends all supplied text through the server to that fixed provider with storage disabled. The app does not persist the key or review. Quotes and segment coverage are checked, while interpretation still needs human inspection. Cancel stops the page waiting and preserves its draft; it cannot guarantee a provider request already submitted incurred no cost. The local MCP does not require this key.

Use the versioned source download and verify `SHA256SUMS` before `pnpm install --frozen-lockfile`. The matching extension is included in the source ZIP and also supplied separately. Stop all service sessions before backing up or replacing `.local`; see [installation and recovery](INSTALL.md). These files contain private pairing credentials and plaintext review history. The latest browser capture and paginated reviews disappear after process exit and need a fresh capture/review. Malformed saved history is preserved instead of silently resetting the comparison.

Supported scope covers readable captured text and public static HTTPS HTML/text retrieval, explicit user capture, source paging, complete baseline comparisons, and direct old/new text comparison. PDF/OCR, inaccessible frames, automatic signing, continuous monitoring and universal legal accuracy are outside v1. Never infer that a missing topic is absent from the complete agreement.

Run `pnpm check`, `pnpm test:browser`, `pnpm test:website` and `pnpm test:consumer` for controlled regression checks. CI and release packaging verify installed dependencies, the service, loaded extension, hosted-page controls and the actual extracted downloads. Live hosted-model checks use fictional source text and remain separate from those controlled tests. [Earlier dated verification](../VERIFICATION.md) and [real-world validation](REAL_WORLD_VALIDATION.md) retain their original scope and results.
