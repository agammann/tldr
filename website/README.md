# Public website

[Visit Terms TLDR](https://terms-tldr.alx21.chatgpt.site).

These static files are the source for the public example and installation guide on OpenAI Sites. Open `index.html` to inspect them locally. No build step, backend, API key or terms submission service is required.

The sample agreement, summaries and comparison are fictional and predefined. The installed extension and MCP provide the real page review workflow through the visitor's connected assistant.

Publication verified on September 16, 2026 UTC: Sites version 1, source commit `5eb717012f73ae310d298352c2fbb02c5848233d`, public access, deployment succeeded.

Before publication, the three example tabs and citation expansion passed browser checks. Layout checks passed at widths 320, 390, 768 and 1440 pixels with no horizontal overflow or JavaScript page errors.

Website changes must also be published to the existing Sites project. Updating these GitHub files alone does not deploy the site.
