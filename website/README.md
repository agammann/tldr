# tldr website

[Visit tldr](https://terms-tldr.alx21.chatgpt.site).

Static source for the public example and installation guide on OpenAI Sites. No build step, backend, API key or terms submission service is required. The example agreement, review and comparison are fictional and predefined.

The redesigned edition uses Manrope and DM Sans typography, dark surfaces, lime accents, responsive review cards and reduced motion support. All original citation, tab, copy and installation interactions are preserved.

Website changes must also be published to the existing Sites project. Updating these GitHub files alone does not deploy the site.
