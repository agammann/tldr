ON YOUR COMPUTER

A little setup.
A clearer agreement.

Use Chrome or Edge and an assistant that supports local MCP servers. You’ll need Node.js 22 or later and pnpm 11.19.0.

This public site has the example and guide. The browser extension and MCP run on your computer. Your connected assistant handles the AI review.

Download project ZIP ↗Full setup documentation ↗
1

Get the MCP

Clone the project, or extract the ZIP and open a terminal in its folder. Then install its dependencies.

git clone https://github.com/agammann/terms-tldr.git
cd terms-tldr
pnpm install --frozen-lockfile

Install Node.js and pnpm first if needed.

2

Connect your assistant

In your assistant’s MCP settings, use node as the command and the full path to src/server.mjs as its argument. Replace the example path below with your own.

{
  "mcpServers": {
    "terms-tldr": {
      "command": "node",
      "args": ["/absolute/path/to/terms-tldr/src/server.mjs"]
    }
  }
}

For Windows JSON, use forward slashes in the path or escape each backslash. If Node is not on PATH, use its full executable path. The assistant starts the MCP; reload its connection after configuration.

Using Codex?

Register the server with the CLI, replacing the example path:

codex mcp add terms-tldr -- node "/absolute/path/to/terms-tldr/src/server.mjs"

In the desktop app, find MCPs in Settings. In the version tested, this is under Plugins → MCPs. Keep Terms TLDR enabled and restart the connection after adding it.

3

Add the browser extension

Open chrome://extensions in Chrome or edge://extensions in Edge. Enable Developer mode, choose Load unpacked, and select the project’s extension folder.

Pin Terms TLDR. In its popup, expand Connect to your local MCP and import the project’s .local/pairing.json file. Your running MCP creates this private pairing file. Keep it on your computer.

Open a terms page, click Capture this page, then ask your assistant:

Review my captured terms. Read all source pages. Tell me the important terms, what changed, and any red flags. Cite the clauses and preserve exceptions.

Know the boundaries.

Does this site read my current tab?

No. The website is a public example and installation guide. After installation, the extension captures the page only when you click it. Your assistant reviews that snapshot, which may differ from your current tab.

Where does the text go?

The extension sends the capture to the MCP on your computer. The latest capture stays in memory. Complete reviewed pages become local plaintext baselines for up to 30 URLs. Your AI assistant receives the text when reviewing it, so its data policies apply. This website has no terms submission form and makes no AI requests.

Can it tell me what changed?

Yes, after a first complete review establishes a baseline for that URL. Checks are on request, not continuous monitoring. Text changes can reflect layout or navigation changes. A partial capture never replaces a full baseline.

What has been tested?

The MCP has 15 passing controlled tests, including multiple assistant sessions sharing one capture. Chrome and Edge capture checks passed on real public terms pages. The installed Codex connection retrieved all 92 clauses of a Dropbox capture across two pages and correctly recognized an unchanged repeat review.

What should I double check?

Linked policies, your location, your plan and the exact agreement shown at signup. PDF extraction, inaccessible frames and automatic agreement acceptance are outside this version. The assistant’s summary can miss or misinterpret terms; source citations help you inspect its reasoning.
